Please report any security issues or vulnerabilities in this repository to <obbywiki@wou.gg> and/or <w@wolfite.dev>, do not create an issue here or anywhere public.

What counts as a security vulnerability/issue:

* Flaws that can be used to gain an entry point into a system, container, or anywhere privelleged.
* Flaws that allow for stored XSS or similar vulnerabilities.
* Flaws that reveal sensitive or private user details when they should not be public (e.g., core hides something when a user logs out, but .
* Any other type of issue regarding user privacy.
* Flaws that bypass intended permissions/user rights.
* Flaws that allow for impersonation or data manipulation.
* Flaws that can overwrite, hide, obfuscate, or otherwise delay or block user action logs.
* Destructive changes that are not correctly logged.
* SQLi or other injection vulnerabilities.
* Flaws that allow for unintended or malformed arbitrary text in UI (e.g., flaws that allow for convincing phishing emails via invites, gates, etc.).
* Flaws that allow for bypassing rate limiting measures or other anti-abuse patterns.
* ...Anything else that is plausibly a security issue.

What does not count as a security concern:

* A traditional bug that degrades user quality but does not affect safety, stability, or integrity.

For alternative methods of contact, please see the footer of <https://obby.wiki/> for socials such as Discord.
